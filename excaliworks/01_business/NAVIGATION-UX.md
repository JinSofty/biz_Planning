# 구성도 탐색과 장비 정보 UX

갱신일: 2026-10-22
상태: 사용자 진술·확정 방향과 AI 제안을 구분한 논의 기록 / 신규 구현·실행 검증 없음

## 사용자 회사의 현재 문제 (사용자 진술)

모든 아키텍처·네트워크 구성도를 PowerPoint로 작성한다.

1. 전체 네트워크 구성도가 복잡해 한눈에 이해하기 어렵다.
2. 업무 인수인계와 신입사원 네트워크 교육에 활용하기 어렵다.
3. 네트워크 설계서는 비밀로 관리해 공유가 어렵고, 타팀 요청에 하드카피로 제공한다.
4. 제안서에는 별도로 축약한 구성도를 사용한다.
5. 각 팀 담당자가 PowerPoint 파일을 개별 관리해 공유가 부족하다.
6. 회사에 어떤 구성도가 있는지 파악·검색하기 어려워 담당자에게 문의한다.
7. 장비의 관리 주체·시스템·IP·도입연도·모델 정보는 별도 Excel 자산목록에서 확인해야 한다.
8. 임원 보고용 아키텍처 구성도를 별도로 작성·관리한다.
9. 신규 장비 도입 등 변경이 구성도에 적시에 반영되지 않는다.

외부 조사 결과나 다른 고객의 검증된 수요가 아니며, 첫 상품과 우선순위를 확정한 것은 아니다.

## 확정 방향

[DEC-004](../03_decisions/DEC-004-obsidian-navigation-and-device-popup.md): Obsidian·Excalidraw 중심, 별도 웹사이트 상품 제외, 줌 탐색, 장비 정보 팝업 선호.

## 사용자 경험 제안 (미확정)

- 전체 구성도를 넓게 표시하고 검색·목록·설명 노트는 필요할 때 사용한다. 요약 안내도 시작안도 비교 대상이다.
- 초기 배율은 실제 구성도와 창 크기에 맞춰 전체 맞춤으로 실험한다. 10%, 5~15% 등 대화의 수치는 예시이며 검증된 권장값이 아니다.
- 장비 선택 → 핵심 정보 팝업 → 필요 시 상세 노트·운영절차 열기. 다른 장비 선택 시 교체, 빈 공간/Esc로 닫기, 확대·이동 시 닫기 등은 AI 제안이다.
- 팝업 필드 후보: 장비명·용도·관리팀·담당 창구·허용된 IP·모델·도입연도·정보 확인일·출처·관련 문서.
- 같은 구성도의 상세는 확대·이동하고, 다른 상세도·설명·운영자료는 링크로 연결한다.
- 교육용 설명 경로, 업무별 보기, 임원용 요약, 변경 전후 비교는 후속 제안이다. 자동 생성·권한별 제공·원본 변경 자동 반영은 구현 사실이 아니다.

## 기능 구분과 기술 검증 범위

- 링크: 도형에서 Obsidian 노트나 다른 구성도로 이동.
- 임베드: 노트 또는 특정 제목/블록의 내용을 현재 그림 안에 표시. 텍스트 표시와 조작 가능한 문서 임베드를 구분한다.
- 영역 참조: 원본 Excalidraw의 기준 요소 주변을 표시. 그룹 참조: 지정 요소와 같은 그룹을 표시.
- PDF·SVG를 이미지 하나로 가져오면 내부 장비가 독립 도형·자산으로 자동 식별되지 않는다. 장비 클릭 영역과 노트/Entity 연결이 필요하다.
- 큰 배경 이미지의 일부가 영역 참조로 정확히 잘리는지, 확대 품질·성능·새로고침 동작은 미검증이다.
- 기본 링크 미리보기와 '한 번 클릭해 팝업 열기'는 같다고 가정하지 않는다. 실제 버전·모드·설정별 동작과 추가 개발 필요 여부를 확인한다.
- 배율별 의미정보 자동 표시, 원본 변경 시 클릭 영역 자동 추적은 별도 개발·검증 대상이다.
- 화면에서 민감 정보를 가리는 것만으로 접근 제어가 되지 않는다. 보관함·파일 접근과 공유 범위를 별도 설계한다.

## 다음 검증 제안

1. 실제 구성도 한 구간·장비 두 개에 클릭 영역과 설명 노트를 연결해 팝업 동작, 확대·이동과의 충돌, 정보 가독성을 확인한다.
2. PDF/SVG의 영역 참조·확대 품질 및 PowerPoint 재출력 후 클릭 위치·참조 범위 정합성을 확인한다.
3. 실제 Excel 자산목록과 구성도 사이 공통 식별자·갱신 책임을 확인한다. 현재 공통 식별자 존재 여부는 답변받지 못했다.
