# PowerPoint → PDF 기반 ArcMAP 탐색

- 갱신일: 2026-10-21 (한국 시간)
- 상태: PDF 출력 형식 채택 확정. 사용자 PDF 선명도 확인 완료. Excalidraw 반입 후 품질·성능은 미검증.
- 결정: [DEC-003](../03_decisions/DEC-003-pdf-map-exploration.md)

## 현재 흐름

1. PowerPoint의 큰 슬라이드에 전체 네트워크 구성도를 상세 작성한다. PowerPoint 파일을 작성·수정 원본으로 유지한다.
2. 구성도를 PDF로 내보낸다. 사용자가 PDF에서 선명도가 유지됨을 확인했다.
3. Excalidraw에서 PDF 내용을 지도처럼 확대·축소 탐색하는 방식을 검증한다. 반입·표시 방식 및 변환 필요 여부는 아직 확정하지 않았다.
4. 한 구성도 안에서는 전체 구조 → Zone·영역 → 장비명·연결 설명을 위치 맥락을 유지하며 읽는다.
5. 더 상세한 Zone·클러스터나 설계·운영 문서는 파일 연결과 플러그인의 프레임 방식 등을 활용해 이동한다. 구체 동작·제약·복귀 경험은 검증 대상이다.

## 확인된 것과 남은 것

- 사용자 확인: Windows PowerPoint의 저장 형식에 SVG 항목이 보이지 않았음. PDF 저장 후 선명도는 유지됨.
- 미확인: PowerPoint 제품 버전·빌드, 실제 PDF의 규모·확대 배율·저장 설정, Excalidraw 반입 후 품질·성능.
- 핵심 주의점: PDF 파일 자체가 선명해도 가져오는 과정에서 이미지 변환이 발생하면 최종 확대 품질은 달라질 수 있다.
- 갱신 관리: 원본과 PDF의 대응·반영 시점을 관리하고 출력물 교체 후 링크·프레임 위치가 맞는지 확인한다.
- 후속 기능: 개별 자산 검색·선택·CVE 강조·관계 분석에는 자산과 그림 위치를 연결하는 별도 설계가 필요하다.
- 객체 수: 약 1,000개 제한은 초기 논의 가설이며 채택된 상한이 아니다. 실제 파일과 실행 환경에서 적정 범위를 검증한다.

## 이력

처음에는 [PowerPoint → SVG 아이디어](SVG-MAP-EXPLORATION.md)를 기록했다. 이후 사용자의 실행 확인과 명시적 결정으로 출력 형식을 PDF로 변경했다. 이전 아이디어는 경위 보존을 위해 유지한다.
