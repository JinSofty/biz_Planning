## 현재 단계
ArcMap 요소기술 검증 중. 첫 객체 배치는 실제 실행에 성공했다. 줌 탐색 UX, AI 연결, 제품 전체 구현과 고객 검증은 아직 완료하지 않았다.

## PDF 기반 지도 탐색 결정 (2026-10-21)
- PowerPoint의 큰 슬라이드에 상세 네트워크 구성도 작성 → PDF 내보내기 → Excalidraw에서 줌 탐색을 검증하는 방향. 추가 상세는 파일 연결·프레임 방식 등으로 이동한다.
- 사용자가 PDF 선명도 유지를 확인하고 SVG 대신 PDF를 사용하기로 확정했다. [DEC-003](../03_decisions/DEC-003-pdf-map-exploration.md), [현재 방식](../01_business/PDF-MAP-EXPLORATION.md). 기존 SVG 아이디어는 이력으로 보존한다.
- Excalidraw 반입·표시 방식과 반입 후 품질·성능, 상세 이동·복귀, PDF 갱신 후 연결 위치 정합성은 미검증이다. 객체 1,000개 제한도 확정하지 않았다.

2. PDF/SVG 영역 표시·확대 품질과 PowerPoint 재출력 후 클릭/참조 위치 정합성을 확인한다.
3. 구성도와 Excel 자산목록의 공통 식별자 및 갱신 책임을 확인한다. 기존 저장/재열기·취소·서버명 동기화의 실제 검증도 남아 있다.

## 탐색 UX와 사업 범위 (2026-10-22)
- Obsidian·Excalidraw 중심으로 제공하며 별도 웹사이트 상품은 만들지 않는다. 줌 탐색과 장비 정보 팝업 선호를 [DEC-004](../03_decisions/DEC-004-obsidian-navigation-and-device-popup.md)에 기록했다.
- 사용자 회사의 PowerPoint 구성도와 Excel 자산목록 관련 아홉 가지 문제를 [탐색 UX](../01_business/NAVIGATION-UX.md)에 정리했다. 외부 고객 수요 검증이나 최초 유료 상품 확정은 아니다.
- 팝업 필드·클릭/닫기 동작·시작 화면·배율은 미확정이다. 이번 대화에서 신규 구현·실행 검증은 하지 않았다.
- PDF 선택은 유지한다. SVG/PDF 응용 검토와 영상 조회 한계는 UX 문서에 구분했다.

## 직원 간 콘텐츠 공유 (2026-10-22 확정)
- 고객사 보안 콘텐츠는 사내 GitLab/Git으로 관리한다. 사업 기획 기록용 GitHub와 구분한다.
- 담당 영역·파일 책임 중심으로 공통 브랜치 직접 반영을 허용한다. 사전 승인·잠금은 일률 의무화하지 않는다.
- 최신 변경 수신, 관련 변경만 전송, 타인 수정 알림, 강제 덮어쓰기 금지, 충돌본 보존·취소 커밋 복구, 열람 범위별 저장소 분리를 원칙으로 한다. [DEC-005](../03_decisions/DEC-005-internal-gitlab-content-sync.md).
- GitLab 설치·권한·Obsidian 받기/전송 UI·실제 충돌 복구·Registry revision 연결은 설계/검증 전이다.

## 개발 브랜치 진행 (2026-10-21)
- `feature/arcmap-webserver-enhancements`: 좁은 Zone 자동 축소, 기존 서버 몸통 너비 기준 크기 맞춤, 빈 공간 탐색 구현.
- 몸통·선·텍스트를 같은 비율로 조절. 크기 기준 서버가 여럿이면 중앙값을 사용하고 공간 부족 시 새 서버만 추가 축소.
- 최종 수정의 실제 Obsidian 화면 정상 동작을 사용자가 확인했다. 독립 모의 테스트 10개 통과.
- 저장/재열기·실행 취소·작은 글자 가독성의 별도 확인은 남아 있다.
- [개발 세션 기록](../04_sessions/2026-10-21-webserver-autoscale.md). 개발 브랜치에 커밋. 후속 사용자 요청에 따라 GitHub로 전송하며 main 병합은 하지 않는다.

## 서버명 동기화 개발
- 서버명 라벨 첫 줄 → 내부 serverName 자동 동기화, 기존 서버 보정, 중복/빈 이름 경고 구현.
- `ArcMap-Sync-ServerNames` 전용 스크립트의 플러그인 자동 시작 등록 지원. 사용자가 최초 실행 시 자동 시작 허용 필요.
- 배치 테스트 10개와 동기화 모의 검증 통과. 실제 Obsidian 편집·저장/재열기·취소 확인은 남아 있음.
