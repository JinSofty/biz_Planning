# DEC-003: PowerPoint 구성도의 탐색용 형식을 SVG에서 PDF로 전환

- 상태: 확정 (탐색용 출력 형식 선택). Excalidraw에서의 최종 품질·성능 검증은 남아 있음.
- 날짜: 2026-10-21 (한국 시간)
- 확정 근거: 사용자가 “pdf가 선명하게 유지된다. svg파일보다 pdf로 해야겠다. 이 결정된 내용을 저장해줘”라고 확인·요청했다.
- 결정 내용: PowerPoint에서 상세 네트워크 구성도를 작성·수정하고 PDF로 내보내는 방식을 채택한다. 이전 SVG 아이디어의 출력 형식을 PDF로 변경한다. Excalidraw에서 지도처럼 확대·축소하고 추가 상세는 파일 연결·프레임 등으로 이동하려는 UX 방향은 유지한다. PDF를 가져오거나 표시하는 구체 방식은 검증 후 정한다.
- 검토한 대안: PowerPoint 슬라이드의 직접 SVG 저장. 사용자는 Windows용 PowerPoint의 저장 형식에서 SVG 항목을 찾지 못했다고 보고했다. 정확한 제품 버전·빌드는 확인하지 않았으므로 Windows 전체에서 SVG가 불가능하다는 의미는 아니다.
- 이유와 근거 자료: 사용자가 PDF 저장 후 선명도가 유지됨을 실제 확인했다. 사용자 실행 결과이며 AI가 파일이나 화면을 직접 검사한 것은 아니다. 원본 구성도 규모·확대 배율·글꼴·저장 설정·실행 환경의 수치는 확인되지 않았다.
- 예상 영향: SVG 직접 저장 지원에 의존하지 않고 PDF를 탐색용 출력물로 활용한다. PDF 자체의 선명도 확인과 Excalidraw에 가져온 뒤의 렌더링 품질은 별개의 검증 범위다. 이미지 변환이 개입하는지와 확대 품질·성능은 아직 미확인이다.
- 재검토 조건: Excalidraw 반입 후 선명도 저하·성능 문제, 파일 연결·프레임 이동 제약, 원본 변경 후 출력물 및 연결 위치 갱신 부담이 확인될 때.
- 이전/후속 결정: [SVG 기반 탐색 아이디어](../01_business/SVG-MAP-EXPLORATION.md)의 출력 형식 선택을 대체한다. DEC-001의 Entity/Registry·Draft/Publish 기준선을 변경하지 않는다. 객체 1,000개 제한도 확정하지 않는다.
- 함께 갱신할 문서: STATUS.md, README.md, SVG 아이디어 문서의 후속 결정 안내, PDF 탐색 방식 문서.

## 다음 검증

1. 실제 PDF를 대상 Obsidian·Excalidraw에서 가져오거나 표시해 작은 장비명·선·글꼴과 확대·축소 반응을 확인한다.
2. Zone 상세 자료의 파일 연결·프레임 활용과 원래 위치 복귀를 확인한다.
3. PowerPoint 원본 수정 → PDF 재생성 → 탐색 화면 갱신 시 연결 영역의 정합성을 확인한다.
