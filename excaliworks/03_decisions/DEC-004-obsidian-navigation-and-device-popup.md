# DEC-004: Obsidian·Excalidraw 중심 탐색과 장비 정보 팝업

- 상태: 확정 (사업 제공 방식·탐색 방향·팝업 선호). 구체 구현·동작은 미검증.
- 날짜: 2026-10-22 (한국 시간)
- 확정 근거: 사용자가 Obsidian과 Excalidraw 이용이 주 사업이며 별도 웹사이트 상품을 만들지 않는다고 명시했다. 줌인·줌아웃 탐색을 요청하고, 장비 클릭 시 팝업/미리보기로 정보를 보여주는 방식을 선호한다고 말했다. 이후 확인 사항 커밋을 요청했다.
- 결정 내용:
  1. 고객 사용 화면은 Obsidian·Excalidraw를 중심으로 구성한다. 별도 웹사이트 상품은 이번 사업 범위에 포함하지 않는다.
  2. 구성도 탐색은 줌인·줌아웃을 중심으로 설계한다.
  3. 장비 선택 시 관련 정보를 팝업/미리보기로 제공하는 방향을 채택한다. 기본 미리보기 활용과 추가 스크립트/플러그인 필요 여부는 실제 환경에서 검증한다.
- 검토한 대안: 별도 웹앱 형태의 안내 화면, 상시 좌우 패널, 현재 창에서 장비 노트로 이동. 앞선 웹앱 모형은 UX 설명용이며 실제 구현 결과나 채택된 제품 형태가 아니다.
- 이유와 근거 자료: 현재 회사의 PowerPoint 구성도 활용 불편은 아래 요구사항 문서에 사용자 진술로 정리했다. 구성도 맥락을 유지하며 장비 정보를 확인하려는 선호를 반영한다.
- 예상 영향: 기업용 안내도·노트 템플릿·자산 연결·자동화 중심으로 상세화한다. 기존 Registry·Adapter 기술 기준선을 폐기하는 결정은 아니다.
- 재검토 조건: 팝업이 확대·이동·도형 편집을 방해하거나 정보 확인과 복귀가 불편한 경우.
- 이전/후속 결정: DEC-001 기술구조의 사용자 접점을 구체화한다. DEC-003의 PDF 선택은 유지하며 SVG 재비교는 제안 상태다.
- 함께 갱신할 문서: OVERVIEW.md, ARCHITECTURE.md, STATUS.md, NAVIGATION-UX.md.

## 미확정 사항

- 팝업의 필드·크기·열기/닫기·다른 장비 선택 시 교체·고정·상세 노트 이동 방식.
- 장비 전체 클릭과 별도 정보 표시 중 클릭 대상, 편집/보기 모드의 조작 방식.
- 전체도 우선과 별도 요약 안내도 중 시작 화면. 고정 10% 및 예시 배율 구간은 확정하지 않는다.
- 최초 유료 상품·가격·고객 검증과 도입 효과 수치는 미확정이다.
