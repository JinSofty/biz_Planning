# Excaliworks 협업 지침

- 한국어로 협업합니다.
- 세션 시작 시 README.md, 00_context/STATUS.md, 01_business/OVERVIEW.md를 읽고 관련 문서만 추가로 읽습니다.
- 사용자가 말한 사실, AI의 제안, 미검증 가설, 사용자가 확정한 결정을 구분합니다.
- AI 제안을 사용자가 확정한 것처럼 기록하지 않습니다. 예시의 수치와 고객을 실제 사업 정보로 전용하지 않습니다.
- 외부 자료의 주장에는 출처와 확인 여부를 남깁니다. 붙여넣은 AI 답변은 검증된 사실이 아닙니다.
- 주요 결정은 templates/decision.md를 사용해 기록합니다. 기존 결정을 바꾸면 새 기록에서 이전 결정과 변경 이유를 연결하고 과거 기록을 보존합니다.
- 아래 경로는 excaliworks/ 폴더 기준입니다.
- 작업을 마치면 STATUS.md에 최신 상태와 다음 작업을 간결하게 반영합니다. 별도 세션 기록은 결정·실험 근거 등 추가 가치가 있을 때만 남기며, 전송·병합 절차를 반복 기록하지 않습니다.
- 사용자가 저장을 요청했거나 합의한 저장 시점이면 관련 파일만 선별하여 커밋합니다. GitHub 전송 성공 여부를 따로 확인해 보고합니다.
- 원본 대화 전체는 사용자가 업로드 범위를 정하기 전까지 저장소에 복사하지 않습니다. 비밀키와 인증정보는 커밋하지 않습니다.
