# ArcMap 요소기술 검증 세션

- 사용자 방향: 줌 탐색 UX와 1인기업 유지관리 효율을 위한 로컬 온프레미스 LLM Drawing 자동화 검토.
- 명령 예시: DMZ에 웹서버 추가, 서버명·업무·IP·관리조직·담당자 전달. 이 값은 테스트 예시이며 실제 운영자산 확정 정보로 취급하지 않음.
- 구현 접근: LLM은 구조화 명령 추출, 실행기는 심볼 선택·ID 연결·배치를 수행. 아직 LLM을 연결하지 않음.
- 첫 검증: 라이브러리 Web 심볼을 선택한 DMZ에 배치하는 Excalidraw 스크립트 작성·설치.
- 오류 해결: Markdown 설명·코드 상자가 실행 컴파일을 막아 YAML 아래 코드만 남김.
- 사용자 결과: 그림 정상 생성 확인.
- 상세 기록과 실행 파일: [POC-001](../06_validation/POC-001-library-placement/RESULT.md).
