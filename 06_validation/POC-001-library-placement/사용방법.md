# ArcMap 첫 배치 테스트

대상: Obsidian Excalidraw 2.29.0. 로컬 라이브러리 첫 항목(Web, 17개 요소)을 사용합니다.
원본 심볼은 roughness 0입니다. 이 테스트는 선·색·seed를 유지하며 손그림 스타일을 새로 적용하지 않습니다.

## 설치
1. 함께 제공된 `ArcMap-Place-WebServer.md` 파일을 Vault의 `Excalidraw/Scripts` 폴더로 복사합니다.
2. `.md` 확장자를 유지합니다. 플러그인 설정은 변경하지 않습니다.
3. 스크립트가 목록에 없으면 Drawing을 다시 열거나 Obsidian을 재시작합니다.

## 실행
1. 새 테스트 Drawing을 만듭니다.
2. 가로 600, 세로 400 정도의 빈 사각형을 그리고, 위쪽에 DMZ 제목을 넣습니다. 제목은 상단에 두세요.
3. 사각형 테두리 하나를 선택합니다. DMZ 이름 검색은 아직 하지 않습니다.
4. Drawing의 Excalidraw 스크립트 도구 목록에서 `ArcMap-Place-WebServer`를 실행합니다. 도구 목록은 보통 팔레트 아이콘으로 열 수 있습니다. 위치는 레이아웃에 따라 다를 수 있습니다.
5. 웹서버와 `web_007`, `10.0.0.250` 라벨이 추가되고 선택되는지 확인합니다.
6. Shift+2로 선택 영역을 확대합니다.
7. 저장하고 Drawing을 닫았다가 열어 모양과 그룹 이동을 확인합니다.
8. 추가 직후 Cmd+Z로 취소가 정상 동작하는지도 별도로 확인합니다. 한 번의 취소로 모두 제거되는지는 실제 환경에서 확인해야 합니다.

## 확인할 결과
- DMZ 안에 라이브러리 원본과 같은 모양의 Web 심볼이 생성됨.
- 그림·라벨이 함께 이동하고 라이브러리 원본은 변하지 않음.
- 저장 후 다시 열어도 유지됨.
- 다시 실행하면 web_007 중복 생성이 차단됨.

## 범위
AI·CMDB·Registry·자동 DMZ 검색·자동 줌은 아직 연결하지 않았습니다.
Zone 이동 시 서버가 따라가는 기능은 없습니다. DMZ는 일반 사각형이며 연결은 테스트 메타데이터로만 기록합니다.
업무·담당자 정보 입력은 다음 단계입니다.

## 검증 상태
실제 라이브러리로 모의 실행해 ID/그룹 재매핑·배치·스타일 유지·오류 분기를 검사했습니다.
Obsidian 실제 화면에서 그림이 정상 생성되었음을 사용자가 확인했습니다. 저장 후 재열기·취소·그룹 이동·스타일 비교는 별도 확인이 남아 있습니다.

## 개발 브랜치: 자동 크기 조절
존 안의 같은 Web 심볼 크기를 우선 따릅니다. 여러 크기가 있으면 중앙값을 사용합니다. 동일 크기로 들어갈 공간이 없으면 새 서버와 라벨을 함께 더 축소하고 알림을 표시합니다. 임의로 수정한 다른 심볼은 자동 식별하지 못할 수 있습니다. 기존 객체는 이동하거나 축소하지 않습니다. 이 변경은 모의 테스트 10개를 통과했으며, 최종 수정 후 실제 Obsidian 화면에서 전체 비례 축소가 정상 동작함을 사용자가 확인했습니다. 저장/재열기·실행 취소는 별도 확인이 남아 있습니다.
