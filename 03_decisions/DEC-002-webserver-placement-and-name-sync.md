# DEC-002: 웹서버 배치의 비례 축소와 서버명 동기화

- 상태: 확정 (개발 요구사항). 제품 전체 배치 정책은 미확정.
- 날짜: 2026-10-21
- 확정 근거: 사용자가 존 안의 서버와 크기를 맞추고 전체 그림을 비례 축소하도록 요청했으며, 최종 수정 후 “좋아 제대로 잘됬어. 커밋해”라고 확인했다. 이후 “중복 검사에 사용하는 서버명이야. 텍스트를 수정하면 내부 서버명도 자동으로 동기화되도록 해줘.”라고 요청했다.
- 결정 내용: 존 내 기존 서버 몸통 너비를 크기 기준으로 삼고 공간 부족 시 그림·라벨을 함께 축소한다. 서버명 라벨 첫 줄 변경 시 내부 serverName과 중복 상태를 동기화한다. Excalidraw 요소 ID는 유지한다.
- 검토한 대안: 기존 크기 부족 시 추가 중단, 서버명 텍스트와 내부 이름 별도 관리. 정렬·상대 배치·Zone 확장·최소 가독성 정책은 후속 제안으로 보존한다.
- 이유와 근거 자료: 사용자 요청과 실제 화면 검증 및 [배치 세션](../04_sessions/2026-10-21-webserver-autoscale.md), [이름 동기화 세션](../04_sessions/2026-10-21-server-name-sync.md).
- 예상 영향: 좁은 존에서 배치 가능, 이름 변경 후 이전 이름으로 중복 차단되는 문제 해소. 동기화는 모의 검증만 통과했으며 실제 Obsidian 검증은 남아 있다. 자동 시작은 플러그인에서 최초 허용 필요.
- 재검토 조건: 가독성 저하, 서버 그룹 오인식, 편집/취소/재열기 시 동기화 오류, 수동 보정 포함 작업시간 증가.
- 이전/후속 결정: DEC-001의 사업·기술 기준선을 변경하지 않는 POC 개발 결정. [자동 배치 한계와 개선안](../01_business/LAYOUT-LIMITS-AND-VALIDATION.md)은 확정된 구현 계획이 아니다.
- 함께 갱신할 문서: STATUS.md, 각 개발 세션 기록, POC 사용방법.
